# Madhav Ecommerce Sales Analysis Dashboard

## Project Overview
The Madhav Ecommerce Sales Analysis Dashboard is an interactive business intelligence project developed using Microsoft Power BI. It focuses on analyzing ecommerce sales performance, profitability, customer purchasing behavior, and regional sales trends.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## Dashboard Features

- **KPI Analysis:** Total Amount, Total Quantity, Total Profit, and Average Order Value (AOV).
- **Monthly Profit Analysis:** Tracks profit trends across different months.
- **Sub-Category Analysis:** Compares profitability across product sub-categories.
- **Category Analysis:** Analyzes product category-wise quantities.
- **Payment Mode Analysis:** Examines customer payment preferences.
- **Customer Analysis:** Identifies sales contribution by customers.
- **State-wise Analysis:** Compares sales performance across states.
- **Interactive Filters:** Quarter and State slicers for dynamic analysis.

1. Download the `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Explore the dashboard using interactive filters.

## Project Objective
To transform ecommerce sales data into meaningful business insights through interactive visualizations and help understand sales performance, profitability, and customer trends.
